作品展示墙
一个基于原生 HTML/CSS/JavaScript 实现的图片作品展示与投票应用，无需任何框架或依赖，打开即用。

功能特性
上传作品：选择本地图片

作品展示墙：展示上传的作品

投票功能：为任意作品投一票，票数实时更新

最高票数：顶部实时显示当前所有作品中的最高票数

技术栈
HTML5：语义化结构

CSS3：Flexbox + Grid 布局、渐变、动画、响应式设计

原生 JavaScript：无框架、无依赖

使用说明
在浏览器里直接打开 index.html

点击「选择图片上传」，从本地选择一张图片

预览无误后点击「发布作品」，作品会出现在下方展示墙

点击任意作品卡片上的「投一票」为该作品投票

右上角会实时显示当前最高票数

已知缺陷
只能上传图片文件

无法限制个人投票次数

说明
本项目为纯前端实现，数据仅保存在当前页面会话中，刷新页面后数据将丢失。如需持久化存储，可自行接入 localStorage 或后端接口。
